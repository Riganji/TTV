# TelikTV — IPTV-плеер для Android TV

Kotlin + Jetpack Compose + Media3 (ExoPlayer). Парсер — порт вашего `parser.py` (telik.live → iframe-плееры → m3u8/mpd), работает прямо на устройстве.

## Сборка
1. Android Studio Ladybug или новее → Open → папка `TelikTV`, дождаться Gradle Sync (wrapper скачается сам).
2. Запуск: эмулятор Android TV (API 30+) или приставка по `adb connect <ip>` → Run.
3. Тесты парсера: `./gradlew :app:testDebugUnitTest`.

Минимальный Android — 8.0 (API 26).

## Управление пультом
| Где | Кнопка | Действие |
|---|---|---|
| Список | ↑ ↓ ← → / OK | навигация по группам и каналам / открыть канал |
| Плеер | ↑ ↓ (CH+/CH−) | предыдущий / следующий канал в группе |
| Плеер | ← → | предыдущий / следующий поток канала |
| Плеер | OK / Menu | панель со списком потоков (выбор — OK) |
| Плеер | Назад | закрыть панель / вернуться к списку |

## Как устроено
- `Config.kt` — список каналов по группам, UA, игнорируемые хосты (из `parser.py`).
- `Extract.kt` — чистая логика разбора (regex, base64, url-encoded, iframe, вкладки-потоки, заголовок). Без Android → покрыта JVM-тестами.
- `TelikScraper.kt` — сеть (OkHttp, cookies, ретраи, Referer/iframe-заголовки как в `get_player()`), 4 канала параллельно.
- `Model.kt` — `Channel` со списком `StreamItem` (несколько потоков на канал сгруппированы).
- `MainViewModel.kt` + `ChannelRepository.kt` — кэш `channels.json`, фоновое обновление при запуске, перепарсинг одного канала.
- `ChannelListScreen.kt`, `PlayerScreen.kt` — интерфейс. Плеер шлёт `Referer` = origin плеера (аналог `#EXTVLCOPT:http-referrer`).

## Поведение
- При запуске сразу показывается кэш, каналы обновляются в фоне (счётчик в левой колонке).
- Если поток не открылся — один раз автоматически перепарсивается канал (токены в ссылках протухают) и воспроизведение повторяется.
- Выбранный поток запоминается для канала до выхода из плеера.
