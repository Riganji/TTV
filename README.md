# TelikTV — IPTV-плеер для Android TV (v0.2)

Kotlin + Jetpack Compose + Media3 (ExoPlayer). Парсер — порт `parser.py` (telik.live → iframe-плееры → m3u8/mpd), работает на устройстве.

## Сборка
- Android Studio (Ladybug+) → Open → папка `TelikTV` → Gradle Sync → Run на эмуляторе Android TV / приставке.
- Или онлайн: залить в GitHub — `.github/workflows/build.yml` соберёт APK (вкладка Actions → Artifacts).
- Тесты чистого ядра (парсер, XMLTV, группы): `gradle :app:testDebugUnitTest`.

Минимальный Android — 8.0 (API 26).

## Управление пультом
**Список**

| Кнопка | Действие |
|---|---|
| ↑ ↓ | по группам / каналам |
| ← → | группы ↔ каналы; со строки канала → на ★ |
| OK на канале | смотреть |
| OK на ★ | добавить / убрать из избранного |
| красная строка «Не загрузились…» | OK — отчёт: какие каналы и почему |

**Плеер**

| Кнопка | Действие |
|---|---|
| ↑ ↓ (CH+/CH−) | предыдущий / следующий канал в текущей группе |
| **←** | оверлей со списком каналов |
| **← ещё раз** (в списке каналов) | категории: «Избранное», «Все каналы», группы |
| **→** (или Menu) | оверлей выбора потока |
| OK | карточка «сейчас / далее» из телепрограммы |
| Назад | категории → каналы → закрыть → выход в список |

В оверлее каналов: → со строки переходит на ★, ← возвращает на строку (а со строки ← открывает категории).

## Что есть
- **Избранное** — группа «Избранное» (хранится на устройстве); если оно не пустое, приложение открывается на нём.
- **Логотипы** — берутся со страницы канала (`Extract.findLogo`: картинка со slug в адресе → alt с названием → og:image → «logo» → image_src); если на странице нет — иконка из XMLTV; иначе инициалы. Один и тот же адрес у 3+ каналов считается баннером сайта и отбрасывается.
- **Телепрограмма (EPG)** — XMLTV (.xml / .xml.gz) из `Config.EPG_URLS`, потоковый разбор, кэш 6 часов. Показывается «сейчас в эфире» в списках, прогресс и «далее» по OK. Каналы сопоставляются по названию; если не совпало — добавьте `Config.EPG_ALIASES` (slug → названия из XMLTV).
- **Автопереход при ошибке** — поток не открылся или не стартовал за 20 с → включается следующий поток канала (уведомление сверху); когда перебраны все — один раз перепарсивается канал, затем сообщение об ошибке.
- **Сообщения о загрузке** — каналы, которые не спарсились, перечислены красной строкой над списком и в отчёте (с причиной: 404, 403, «плеер не найден», «в плеере нет ссылок» и т.д.; помечено, если показан сохранённый вариант). В отчёте же — статус телепрограммы и каналы без программы.

## Структура
`Config.kt` (каналы, группы, EPG), `Extract.kt` (разбор страниц, логотипы), `Xmltv.kt` (XMLTV, сопоставление), `Groups.kt`, `Model.kt`, `TelikScraper.kt`, `EpgRepository.kt`, `ChannelRepository.kt`, `MainViewModel.kt`, экраны `ChannelListScreen / ChannelRow / ChannelPanel / PlayerScreen / ReportOverlay`, `TelikApp.kt` (загрузчик логотипов Coil).
