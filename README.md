# TelikTV — IPTV-плеер для Android TV (v0.2)

Kotlin + Jetpack Compose + Media3 (ExoPlayer). Парсер — порт `parser.py` (telik.live → iframe-плееры → m3u8/mpd), работает на устройстве.

## Сборка
- Android Studio (Ladybug+) → Open → папка `TelikTV` → Gradle Sync → Run на эмуляторе Android TV / приставке.
- Или онлайн: залить в GitHub — `.github/workflows/build.yml` соберёт подписанный release-APK (вкладка Actions → Artifacts).

### Подпись (иначе обновление поверх не встанет)
Все сборки должны быть подписаны одним ключом. Создать один раз:
```
keytool -genkeypair -v -keystore app.jks -alias teliktv -keyalg RSA -keysize 2048 -validity 10000
```
Локально — `keystore.properties` в корне (`storeFile`, `storePassword`, `keyAlias`, `keyPassword`).
В GitHub — секреты `KEYSTORE_BASE64` (`base64 -w0 app.jks`), `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`.
Артефакт из Actions скачивается **zip-архивом** — ставить надо распакованный `app-release.apk`, сам архив Android считает повреждённым пакетом.
- Тесты чистого ядра (парсер страниц, расписание, XMLTV, группы): `gradle :app:testDebugUnitTest`.

Минимальный Android — 8.0 (API 26).

## Управление пультом
**Список**

| Кнопка | Действие |
|---|---|
| ↑ ↓ | по группам / каналам |
| ← → | группы ↔ каналы; со строки канала → на ★ |
| OK на канале | смотреть |
| OK на ★ | добавить / убрать из избранного |
| красная строка «Не загрузились…» | OK — отчёт: какие каналы и почему |

**Плеер**

| Кнопка | Действие |
|---|---|
| ↑ ↓ (CH+/CH−) | предыдущий / следующий канал в текущей группе |
| **←** | оверлей со списком каналов |
| **← ещё раз** (в списке каналов) | категории: «Избранное», «Все каналы», группы |
| **→** | оверлей телепрограммы текущего канала |
| **Menu** | оверлей выбора потока |
| OK | карточка «сейчас / далее» из телепрограммы |
| Назад | категории → каналы → закрыть → выход в список |

Любой оверлей закрывается сам через 30 секунд без нажатий (`Config.OVERLAY_TIMEOUT_MS`).

В оверлее каналов: → со строки переходит на ★, ← возвращает на строку (а со строки ← открывает категории).

## Что есть
- **Избранное** — группа «Избранное» (хранится на устройстве); если оно не пустое, приложение открывается на нём.
- **Логотипы** — берутся со страницы канала (`Extract.findLogo`: картинка со slug в адресе → alt с названием → og:image → «logo» → image_src); если на странице нет — иконка из XMLTV; иначе инициалы. Один и тот же адрес у 3+ каналов считается баннером сайта и отбрасывается.
- **Телепрограмма (EPG)** — постранично с `programma-peredach.com`: по одной лёгкой странице на канал и день (сегодня + завтра), только для каналов из `EpgConfig.CHANNEL_MAP`. Общий XMLTV не качается — кэш `epg.json` порядка сотен килобайт вместо десятков мегабайт. Время источника (Москва) пересчитывается в местное. Кэш 6 часов (`EpgConfig.TTL_MS`), каналы подставляются в UI по мере готовности. Нет канала в `CHANNEL_MAP` — программа для него не запрашивается.
- **Автопереход при ошибке** — поток не открылся или не стартовал за 20 с → включается следующий поток канала (уведомление сверху); когда перебраны все — один раз перепарсивается канал, затем сообщение об ошибке.
- **Сообщения о загрузке** — каналы, которые не спарсились, перечислены красной строкой над списком и в отчёте (с причиной: 404, 403, «плеер не найден», «в плеере нет ссылок» и т.д.; помечено, если показан сохранённый вариант). В отчёте же — статус телепрограммы и каналы без программы.

## Структура
`Config.kt` (каналы, группы), `EpgConfig.kt` (источник телепрограммы и маппинг slug'ов), `Extract.kt` (разбор страниц, логотипы), `Peredach.kt` (разбор страницы расписания), `Xmltv.kt` (`Epg`-хелперы; сам XMLTV-парсер оставлен на случай возврата к внешнему источнику), `Groups.kt`, `Model.kt`, `TelikScraper.kt`, `EpgRepository.kt`, `ChannelRepository.kt`, `MainViewModel.kt`, экраны `ChannelListScreen / ChannelRow / ChannelPanel / PlayerScreen / EpgOverlay / ReportOverlay`, `TelikApp.kt` (загрузчик логотипов Coil).
